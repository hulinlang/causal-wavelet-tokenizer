# 实验 0.5 报告：多级分解 + 学习解码器——能否关闭 F11 的收敛差距

**日期**：2026-08-19　**定位**：A　**状态**：✅ 完成（90 runs，真实语音）
**结论先行：不能。** 块布局 + token-wise trunk 下，同码率加深级数对两个前端都有害，因果前端受害更深；F11 的收敛差距不随 L 缩小。且一旦 Haar 也允许多级，F10 的"低码率反超"窗口基本消失。

---

## 1. 数学原理

### 1.1 块 token 布局（两前端精确对齐）

L 级分解的通道（统一为粗→细顺序：[base, ch_L, ..., ch_1]；Haar 前端原始输出为最细在前，需反转细节序列）按 2^L 样本一块打包：

$$\text{token}_j = [\,\text{ch}_0[j],\; \text{ch}_1[j],\; \text{ch}_2[2j{:}2j{+}2],\; \dots,\; \text{ch}_L[2^{L-1}j{:}2^{L-1}(j{+}1)]\,]$$

每 token 携带 $1 + \sum_{i=1}^{L} 2^{i-1} = 2^L$ 个值，故 **N = n/2^L 个 token、C = 2^L 通道，N·C = n 精确**，L=1 退化为阶段 1 布局（N=n/2, C=2）。两前端布局逐位对齐，唯一差异仍是变换本身。

码率轴统一为 **rate = d / 2^L 潜值/样本**（d = latent 维度）。

### 1.2 结构预测

causal_lap 每级的残差只保留偶数位置，奇数位置信息只能经因果平滑尾部渗入下一级基带；级数越深复合损失越大（阶段 0 无参 ceiling：L=1 → 43.0 dB，L=4 → 35.9 dB）。编码端残差细化（F4）只折叠插值误差，无法恢复被抽稀掉的奇数位置。因此先验预期：多级分解**放大**而非缩小收敛差距。

## 2. 实验步骤

- 代码：`experiments/exp05_multilevel_decoder.py`；正确性校验：torch 可微逆变换 vs 前端 numpy 逆变换 max diff ~1e-7（Haar）/ ~5e-4（causal_lap，float32 精度经多级插值）；
- 协议：TokenTrunkAE（C=2^L, width 32, hidden 64），**全部 dec_ln=False**（F9 教训），AdamW 1e−3，batch 2，3000 步，信号域 MSE；验证 64 固定 clips（val-seed 10000），评估点 750/1500/3000；
- 网格：L ∈ {1,2,4} × d ∈ {1,2,4,8,16} × 3 种子 × 2 前端 = 90 runs（L=1 的 d∈{1,2,4} 复用实验 0.4 去 LN 对照组，协议完全相同）；
- 硬件：RTX 4060 Laptop 8GB。

### 3.2 三条读数

1. **同码率加深级数，两前端都变差**：rate=1 时 Haar 66.3 → 63.9 → 52.1（L=1→2→4），causal 49.3 → 45.2 → 43.8。块布局下 L 越大 token 越少越宽（L=4 时 N=1024, C=16），token-wise trunk 在固定步数下更难优化；因果前端额外承受逐层复合的结构损失。
2. **causal 天花板随级数下移**：饱和值 50.9（L=1）→ 46.3（L=2）→ 43.8（L=4），与无参 ceiling 下移（43.0 → 35.9 dB）同向；学习解码器在每级配置之上稳定回收 ~7–8 dB，但追不平级数代价。
3. **极低码率区（rate ≤ 0.25）多级结构对 Haar 有利**：rate=0.5 时 Haar 最佳配置是 L=2（50.97）而非 L=1（46.55）；rate=0.25 时 L=4（46.57）远优于 L=2（41.18）。causal 则始终是 L=1 最优。

## 4. 发现

- **F13（多级路线否决）**：块布局 + token-wise trunk 下，多级分解在同码率上损害两前端，因果受害更深；F11 的收敛差距（rate ≥ 1 时 14–19 dB）在所有 L 上维持，**多级因果金字塔的残差细化无法关闭结构性差距**——损失随级数复合，不是 L=1 伪影。出路清单中的"多级分解 + 学习解码器"一项就此关闭。
- **F14（低码率窗口重估，修正实验 0.4 §5.3）**：F10 曾显示 d=1 时 causal 反超 Haar +3.1 dB；但允许 Haar 同样多级后，Haar 在 rate 0.25–0.5 的最佳配置（L=2/L=4）追平或反超 causal 的最佳配置（L=1）：rate=0.5 时 50.97 vs 49.64，rate=0.25 时 46.57 vs 43.13。**"极端码率甜区"仅在 rate ≤ 0.125 潜值/样本时残存（两者打平）**。因果前端的低码率优势叙事在此协议下不成立。

## 5. 对路线图的影响

1. 阶段 1 的结论定型：**L=1 是因果前端的最优配置**；其收敛差距 13–17 dB（rate ≥ 1）是结构性的，前端层级设计无法消除；
2. 剩余可能缩小差距的机制（均未测）：WAT 的能量稀疏 token 分配（F1 已证跨前端成立，但分配机制本身可能更契合因果前端的能量分布）；学习编码器（阶段 2 混训中编码端可学）；量化后的有效码率重估；
3. 论文定位建议：若坚持定位 A，叙事应收窄为"**流式能力 + 中低码率场景**"（rate ≤ 0.5 时与最佳 Haar 配置差距 ≤ 1.3–6.3 dB，且独享 1 样本首 token / 288 B 状态 / 无损分块），高码率透明重建明确让给非因果基线；
4. 阶段 2（统一输入层混训）建议直接用 L=1 因果前端。

## 6. 局限

1. 块布局（N·C=n 矩形、均匀分配）是特定选择；WAT 式能量稀疏分配、变长 token 流未测——F13 的否决限于本布局/协议；
2. trunk 规模固定（width 32 / hidden 64），L=4 时 C=16 已接近 width；
3. 3000 步固定预算，Haar 后期振荡依旧（取末步值，种子间 42–75 dB 双峰仍在）；
4. 码率是连续瓶颈代理，未量化。
