## 1. 数学原理

### 1.1 时间因果小波前端（Lindeberg, arXiv:2510.05834）

时间因果极限核 Ψ(t; τ, c) 是无穷个截断指数核的级联，其傅里叶变换为

$$\hat\Psi(\omega;\tau,c)=\prod_{k=1}^{\infty}\frac{1}{1+i\,c^{-k}\sqrt{c^2-1}\,\sqrt{\tau}\,\omega}$$

离散实现为一阶递归滤波器级联。给定目标尺度 τ 与分布参数 c > 1，方差预算分配到 K 级：

$$\mu_k^2 = \tau(1-c^{-2})\,c^{-2(k-1)},\qquad \sum_k \mu_k^2 \xrightarrow{K\to\infty} \tau$$

每级为一阶递归（IIR）滤波器：

$$y[t]=(1-a_k)\,x[t]+a_k\,y[t-1],\qquad a_k=e^{-1/\mu_k}$$

该实现**完全时间因果**（不用未来样本）且**时间递归**（每通道 O(1) 内存）。

尺度层级 τ_k = τ_0 c^{2k}，带通小波通道取相邻尺度空间之差：

$$W_k(t)=L(t;\tau_{k+1})-L(t;\tau_k)$$

重建为伸缩恒等式（全长通道下精确成立）：x = L_L − Σ W_k。

### 1.2 码率匹配

Haar 前端有下采样，L 级总系数 = n；因果前端全长通道总系数 = (L+1)·n。为公平对比，新增 `causal_wavelet_rm` 变体：低通通道抽稀至 n/2^L，带通通道 W_k 抽稀至 n/2^(k+1)，**总系数恰好 = n，与 L 级 Haar 标量预算严格一致**。抽稀保留首样本，不读未来样本，因果性保持；重建时线性插值回全长再做伸缩求和，因此**100% 保留时也是有损的**，其 PSNR 记为前端上限（ceiling）。

### 1.3 Haar 前端与能量选择协议（WAT Table 4）

标准 L 级 Haar DWT（正交、精确可逆、非因果）。保留比例 ρ ∈ {50%, 25%, 10%, 5%, 1%}，选择器：energy_global（全局能量 top-k）/ uniform / random（3 种子平均），置零后逆变换测 PSNR（数据范围 1.0）。

## 4. 讨论：四个实质性发现

**F1. 能量分配信号在因果小波下依然有效。** 所有前端下 energy_global 均大幅优于 uniform/random（如 bursts@25%：rm 前端 26.9 dB vs 均匀 13.6 dB）。WAT 的核心结论迁移成立。

**F2. 码率匹配后因果前端在中等码率显著落后，且瓶颈在最细尺度通道。** rm 前端 ceiling 仅 19–38 dB（chirp 甚至低于 Haar@50%）。原因有明确理论解释：最细带通 W_1 = L_1 − x 是高通通道，抽稀到 n/2 后线性插值无法恢复——这是混叠，不是参数问题。**Haar 之所以在 n/2 速率下精确，是因为其基恰好是奇偶交替的 parity 基；任何“光滑因果基 + 下采样”方案对任意信号都不存在完美重建**。这是因果性 + 光滑性的结构性代价，应写进论文作为理论贡献点。

**F3. 因果前端的竞争区间在极端压缩率。** 在 ρ ≤ 5% 处，rm 前端追平甚至反超 Haar（chirp@1%：4.75 vs 4.54；edges@5%：21.0 vs 21.2 持平）。其率失真曲线平坦（ceiling 限制），而 Haar 随码率上升持续受益。**含义：因果小波不适合做高保真重建前端，但可能是极端低码率 + 流式场景的合理选择。**

**F4. 编码端残差细化（因果拉普拉斯金字塔）收益有限，且对高频主导信号反而有害。** causal_lap 将平滑通道的插值误差折叠进残差，对 bursts/edges 的 ceiling 提升约 0.4–1.5 dB；但对 chirp 反而下降 6 dB。原因是因果核的相位延迟：L_1 滞后于 x，残差 r_0 = x − interp(L_1) 中混入延迟误差项，对高频信号尤为显著；群延迟补偿（D = Σμ_k 左移，有界前瞻）消融显示无收益（ceiling 再降约 1 dB），说明误差不只是整数样本平移，还有相位响应形状问题。**最细尺度残差在 n/2 速率下的混叠是根本限制，验证了 F2 的理论判断。**

## 5. go/no-go 判定与定位修正

**判定：条件性 go，但定位必须修正。**

- 按“码率匹配下无参数重建落后 ≤ 3 dB”的字面判据，所有因果方案在中等码率**均未达标**（差距 6–90 dB 不等）。若研究目标是“替代 Haar 做高保真重建前端”，答案是 no；
- 但阶段 0 的无参数协议刻意严苛：tokenizer 的实际重建由**学习到的主干/解码器**完成（WAT 的 Haar 前端也配 MLP 主干），非参数差距是难度的上界而非终局。**因果前端能否被学习解码器救回，本身就是阶段 1 的研究问题**；
- 同时 F3 表明因果前端在 ρ ≤ 5% 极端码率已与 Haar 持平，且独占流式/O(1) 内存能力。

**修正后的论文定位（三选一，建议 A）**：
- **A. 保留因果前端进阶段 1**：假设改为“学习解码器可补偿因果前端的结构性重建差距，同时换来流式能力”，阶段 1 实验直接测量 trunk 关闭差距的程度——差距关闭多少就是论文的核心数据；
- B. 收窄为“极端低码率流式 tokenizer”，只做 ρ ≤ 5% 区间，放弃高保真；
- C. 放弃因果前端，Haar 为主、因果作消融（论文故事最弱）。
