## 1. 数学原理

### 1.1 时间因果小波前端（Lindeberg, arXiv:2510.05834）

时间因果极限核 Ψ(t; τ, c) 是无穷个截断指数核的级联，其傅里叶变换为

$$\hat\Psi(\omega;\tau,c)=\prod_{k=1}^{\infty}\frac{1}{1+i\,c^{-k}\sqrt{c^2-1}\,\sqrt{\tau}\,\omega}$$

离散实现为一阶递归滤波器级联。给定目标尺度 τ 与分布参数 c > 1，方差预算分配到 K 级：

$$\mu_k^2 = \tau(1-c^{-2})\,c^{-2(k-1)},\qquad \sum_k \mu_k^2 \xrightarrow{K\to\infty} \tau$$

每级为一阶递归（IIR）滤波器：

$$y[t]=(1-a_k)\,x[t]+a_k\,y[t-1],\qquad a_k=e^{-1/\mu_k}$$

该实现**完全时间因果**（不用未来样本）且**时间递归**（除滤波器状态外无需历史缓存，每通道 O(1) 内存）。

尺度层级 τ_k = τ_0 c^{2k}，带通小波通道取相邻尺度空间之差：

$$W_k(t)=L(t;\tau_{k+1})-L(t;\tau_k),\qquad L(t;\tau)=\big(\Psi(\cdot;\tau,c)*x\big)(t)$$

重建为伸缩恒等式（精确成立）：

$$x = L_L - \sum_{k=0}^{L-1} W_k$$

### 1.2 Haar 前端（基线，WAT 协议）

标准多层级 Haar DWT：每级 (cA, cD)，cA_j = (x_{2i}+x_{2i+1})/√2，cD_j = (x_{2i}−x_{2i+1})/√2。正交、精确可逆、非因果。

### 1.3 固定码率能量选择（WAT Table 4 协议）

给定保留比例 ρ，对全部系数按能量（平方值）做全局 top-k 保留，其余置零后逆变换重建，测 PSNR（数据范围 1.0）。对照选择器：uniform（等间隔）、random（3 种子平均）。该路径无训练参数，直接检验"系数能量是否为有效的跨模态分配信号"在两个前端下是否成立。

## 2. 实验步骤

1. 合成探针信号（n = 4096，归一化到 [-1,1]）：chirp（变频正弦）、bursts（三种持续时间的瞬态包）、edges（分段平滑+跳变）；
2. 两个前端各 L = 4 级分解，先做**往返精确性断言**（PSNR > 120 dB）；
3. 保留比例 ρ ∈ {50%, 25%, 10%, 5%, 1%} × 三种选择器，重建测 PSNR；
4. 运行命令：`python experiments/stage0_energy_selection.py`（CPU，秒级）。

## 4. 讨论与已知偏差

1. **码率未匹配（重要）**：Haar 有下采样，总系数 = n；因果小波各通道全长，总系数 = (L+1)·n。当前因果前端在"保留系数更多"的条件下 PSNR 仍落后，说明差距真实存在，但数值差被码率不对等扭曲。**正式实验必须按标量预算匹配**（对因果通道做下采样或调整 ρ 定义）；
2. 因果小波落后的可能原因：核不对称 → 能量在通道内扩散；无下采样 → 相邻系数冗余，能量不集中。这正是"流式能力 vs 重建质量"trade-off 的核心数据，待量化；
3. 合成信号仅用于验证管线正确性；**go/no-go 判据（落后 ≤ 3 dB）须在 Speech Commands / DAVIS 音频轨上以码率匹配协议复测后再下结论**；
4. 阶段 0 剩余项：实验 0.2（c ∈ {√2, 2} 的延迟-精度 trade-off）、0.3（流式内存/延迟基准）尚未实现，已列入代码 TODO。
