# 阶段 1 实验报告：共享 token 主干——学习解码器能否关闭因果前端的结构性差距

**日期**：2026-08-19　**定位**：A（保留因果前端，测量学习解码器对阶段 0 差距的关闭程度）
**状态**：合成数据协议完成（WAT 全规模），待真实数据集复测

---

## 1. 数学原理

### 1.1 共享 token 主干（WAT Sec. 4.3）

每个模态/前端把信号分解为 token 序列，token i 携带 C 个系数值 v_i，经适配器与共享主干：

$$e_i = A_{in}(s\,v_i),\qquad z_i = F_{enc}(e_i),\qquad h_i = F_{dec}(z_i),\qquad \hat v_i = A_{out}(h_i)/s$$

F_enc/F_dec 为 LayerNorm-MLP（无注意力、无码本），损失为信号域 MSE：L = ‖x − x̂‖²。

### 1.2 一级分解下的 token 对齐

两前端在 L=1 时 token 布局完全一致（N = n/2，C = 2），唯一差异是变换本身：

- **Haar**：token i = [cA_i, cD_i]，cA/cD 为奇偶样本的和差（parity 基，精确可逆）；
- **causal_lap**：token i = [b_i, r_i]，b = 因果平滑抽稀（一阶递归滤波器级联），r = x − interp(b) 为编码端细化残差。

阶段 0 已证明 causal_lap 在无参数协议下 ceiling 受限（最细残差 n/2 速率混叠，F2/F4）；本阶段的问题是：**学习到的非线性解码器能否利用跨通道相关性补偿该结构性损失**。

### 1.3 可微逆变换

训练中信号域损失要求逆变换可微。L=1 时两者均为 token 的线性运算，以 torch 实现：

- Haar：x̂[2i] = (a_i + d_i)/√2，x̂[2i+1] = (a_i − d_i)/√2；
- causal_lap：x̂ = interp(b) + interp(r)（线性插值上采样，沿序列维度的线性映射）。

## 2. 实验步骤

1. 模型：TokenTrunkAE（C=2, width 32, latent 16, hidden 64），AdamW lr=1e−3，batch 2，300 步——完全对齐 WAT Appendix A.2；
2. 数据：合成音频样探针（随机 chirp / 瞬态簇 / 分段平滑混合，n = 16384，归一化 [-1,1]，PSNR 数据范围 2.0），固定验证种子；
3. 每 50 步在 4 条固定验证样本上测信号域 PSNR；记录峰值显存与耗时；
4. 硬件：RTX 4060 Laptop 8GB，PyTorch 2.11.0+cu128。

运行：
```
python experiments/stage1_shared_trunk.py --frontend haar       # 300 步 n=16384
python experiments/stage1_shared_trunk.py --frontend causal_lap
```

## 3. 结果

| 前端 | 验证 PSNR（300 步） | 峰值显存 | 耗时 |
|---|---|---|---|
| Haar | 48.34 dB | 0.05 GB | 1.4 s |
| **causal_lap** | **51.76 dB** | 0.05 GB | 2.2 s |

训练曲线（val PSNR @ step 50/100/200/300）：

| 前端 | 50 | 100 | 200 | 300 |
|---|---|---|---|---|
| Haar | 34.60 | 42.70 | 47.08 | 48.34 |
| causal_lap | 33.68 | 45.86 | 47.89 | 51.76 |

## 4. 讨论

**F5（核心发现）：学习解码器不仅关闭了因果前端的结构性差距，还反超 Haar 3.4 dB。**
阶段 0 中 causal_lap 的无参数 ceiling 受最细尺度混叠限制；但在配备 token 级 MLP 主干后，模型能学习“从相邻 token 的平滑/残差联合取值预测奇样本细节”的映射——本质上学习了超越线性插值的重构滤波器。因果平滑带来的局部相关性（低频通道 b 携带对未来残差的预测信息）可能正是反超的来源：Haar 的 cA/cD 在同位 token 内信息正交，而 causal_lap 的 b/r 跨 token 冗余更利于 MLP 外推。此解释为假设，需消融验证。

**与 go/no-go 判据的关系**：原判据“落后 ≤ 3 dB”在无参数协议下未达标（阶段 0），但在学习协议下转为**领先 3.4 dB**——支持定位 A 的核心假设。

**限制（必须如实声明）**：
1. 单次运行、单一种子、单一 latent 维度；需 3 种子 + latent ∈ {1,2,4,8,16} 扫描（WAT 的率失真协议）；
2. 合成数据的频谱分布与真实语音不同，**Speech Commands 复测是必要确认**；
3. 当前为一级分解；多级因果金字塔 + 学习解码器的组合尚未测试；
4. 流式优势（O(1) 内存、逐样本延迟）尚未基准量化（实验 0.3）。
