**日期**：2026-08-19　**定位**：A（保留因果前端，测量学习解码器对阶段 0 差距的关闭程度）
**状态**：✅ 真实数据（Speech Commands）复测完成，结论已修正（见 F5 修正）

## 1. 数学原理

### 1.1 共享 token 主干（WAT Sec. 4.3）

每个模态/前端把信号分解为 token 序列，token i 携带 C 个系数值 v_i，经适配器与共享主干：

$$e_i = A_{in}(s\,v_i),\qquad z_i = F_{enc}(e_i),\qquad h_i = F_{dec}(z_i),\qquad \hat v_i = A_{out}(h_i)/s$$

F_enc/F_dec 为 LayerNorm-MLP（无注意力、无码本），损失为信号域 MSE：L = ‖x − x̂‖²。

### 1.2 一级分解下的 token 对齐

两前端在 L=1 时 token 布局完全一致（N = n/2，C = 2），唯一差异是变换本身：

- **Haar**：token i = [cA_i, cD_i]，cA/cD 为奇偶样本的和差（parity 基，精确可逆）；
- **causal_lap**：token i = [b_i, r_i]，b = 因果平滑抽稀（一阶递归滤波器级联），r = x − interp(b) 为编码端细化残差。

阶段 0 已证明 causal_lap 在无参数协议下 ceiling 受限（最细残差 n/2 速率混叠，F2/F4）；本阶段的问题是：**学习到的非线性解码器能否利用跨通道相关性补偿该结构性损失**。

### 1.3 可微逆变换

训练中信号域损失要求逆变换可微。L=1 时两者均为 token 的线性运算，以 torch 实现：

- Haar：x̂[2i] = (a_i + d_i)/√2，x̂[2i+1] = (a_i − d_i)/√2；
- causal_lap：x̂ = interp(b) + interp(r)（线性插值上采样，沿序列维度的线性映射）。

## 2. 实验步骤

1. 模型：TokenTrunkAE（C=2, width 32, latent 16, hidden 64），AdamW lr=1e−3，batch 2，300 步——完全对齐 WAT Appendix A.2；
2. 数据：Speech Commands v0.02（105,829 条 16 kHz wav，单声道，int16/32768 归一化到 [-1,1]，补零/截断至 n=16384；PSNR 数据范围 2.0）；无数据时退回合成探针；
3. 每 50 步在 4 条固定验证样本上测信号域 PSNR；记录峰值显存与耗时；
4. 硬件：RTX 4060 Laptop 8GB，PyTorch 2.11.0+cu128。

运行：
```
python experiments/stage1_shared_trunk.py --frontend haar --data <dataset_root>
python experiments/stage1_shared_trunk.py --frontend causal_lap --data <dataset_root>
```

## 3. 结果

### 3.1 合成数据（单种子）

| 前端 | 验证 PSNR（300 步） | 峰值显存 | 耗时 |
|---|---|---|---|
| Haar | 48.34 dB | 0.05 GB | 1.4 s |
| causal_lap | 51.76 dB | 0.05 GB | 2.2 s |

### 3.2 真实语音（Speech Commands v0.02，105,829 条 wav，3 种子）

| 前端 | 种子 0 | 种子 1 | 种子 2 | 均值 |
|---|---|---|---|---|
| Haar | 51.21 | 51.47 | 51.49 | **51.39 ± 0.12 dB** |
| causal_lap | 49.73 | 49.52 | 49.38 | **49.54 ± 0.14 dB** |

训练曲线（val PSNR @ step 50/100/200/300，合成数据）：

| 前端 | 50 | 100 | 200 | 300 |
|---|---|---|---|---|
| Haar | 34.60 | 42.70 | 47.08 | 48.34 |
| causal_lap | 33.68 | 45.86 | 47.89 | 51.76 |

## 4. 讨论

**F5（修正后）：学习解码器关闭了因果前端的结构性差距——真实数据上差距收窄到 1.85 dB，进入 ≤3 dB 判据。**
合成数据上 causal_lap 曾反超 Haar 3.4 dB，但真实语音复测（3 种子）显示 Haar 领先 1.85 ± 0.2 dB——合成数据的结论过于乐观，已如实修正。两前端均从阶段 0 的“因果前端 ceiling 受限（13–38 dB）”跃升到 ~50 dB 量级：**学习解码器补偿了最细尺度混叠损失的主体**（causal_lap ceiling 约 13–38 dB → 训练后 49.5 dB），残余 1.85 dB 可视为因果性 + 流式能力的当前代价。

机制假设（待消融）：Haar 的 cA/cD 信息正交，而 causal_lap 的 b/r 通道存在跨 token 冗余（因果平滑使 b 携带对邻近残差的预测信息），MLP 主干可学习超越线性插值的重构映射。

**与 go/no-go 判据的关系**：无参数协议下未达标（阶段 0），学习协议下真实数据差距 1.85 dB ≤ 3 dB——**判定 go，定位 A 成立**。论文的诚实表述是“因果前端以约 2 dB 的保真度代价换取流式能力”，而非“反超基线”。

**限制（必须如实声明）**：
1. 3 种子、单一 latent=16；需 latent ∈ {1,2,4,8,16} 率失真扫描，差距可能随码率变化；
2. 验证集仅 4 条样本，验证噪声偏大（Haar 单点曾达 60.6 dB），正式实验应扩大验证批量；
3. 当前为一级分解；多级因果金字塔 + 学习解码器未测试；
4. 流式优势（O(1) 内存、逐样本延迟）尚未基准量化（实验 0.3）——**这是因果前端反超叙事的必要支柱数据**。
